# بيانات مشتركة

- `saudi_admin_divisions.json`: مناطق المملكة الـ١٣ ومدنها ومحافظاتها ومراكزها الإدارية (٢٢٦)، بترتيب الدليل.
  - المصدر: الدليل الموحد لترميز المناطق والمحافظات والمراكز الإدارية — المركز الوطني للعناوين: https://ncar.gov.sa/regions-coding
  - نُقل من ملف PDF أرسله المالك (`saudi_admin_divisions_source.pdf`) في 2026-10-30. صُحّحت كلمات أفسدها استخراج النص من الملف («لا» كانت تُقرأ «ال»): حريملاء، جلاجل، العلا، الأحساء، الهلالية.
  - لا يحتوي على إحداثيات.
