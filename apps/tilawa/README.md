# تلاوة — مولّد مقاطع القرآن (نسخة تجريبية)

## التشغيل على جهازك
1. ثبّت Python 3.10+ و FFmpeg.
2. داخل هذا المجلد:
```bash
pip install -r requirements.txt
python setup_assets.py      # مرة واحدة: نص المصحف (6236 آية) + خط مجمع الملك فهد إلى assets/
streamlit run app.py        # تفتح الأداة في المتصفح
```

## الخطوات في الأداة
1. ارفع التلاوة (صوت أو فيديو).
2. اختر السورة ومن آية إلى آية.
3. اضغط «🔎 تعرّف على الآيات ووقّتها تلقائياً»: يحدد السورة والآيات ويوقّت كل مقطع (يقسم عند وقفات القارئ ويكرر ما أعاده). راجع الجدول وعدّل ما يلزم. أول مرة ينزّل النموذج (~300 ميجا).
4. الخلفية: 5 خلفيات جاهزة أو ارفع صورة/فيديو. التحكم في النص: الحجم، الموضع، المحاذاة، العرض، اللون، الظل. الترويسة (اسم السورة + البسملة) ثابتة لا تختفي.
5. أنتج ← حمّل الفيديو (1080×1920، MP4).

## الملفات
| الملف | الدور |
|---|---|
| `app.py` | الواجهة (Streamlit) |
| `engine/render.py` | محرك الرسم والإنتاج (Pillow + FFmpeg)، يعمل أيضاً من سطر الأوامر |
| `tilawa/quran.py` | نص المصحف وتحويل ترميز التنوين لخط المجمع |
| `tilawa/backgrounds.py` | الخلفيات الجاهزة |
| `tilawa/timing.py` | التوقيت التقريبي وكشف الصمت |
| `tilawa/sync.py` | المزامنة الآلية (Whisper القرآني + المطابقة مع المصحف) |

خط الترويسة المزخرفة: QCF_BSML (مجمع الملك فهد، نفس شرط الترخيص).
