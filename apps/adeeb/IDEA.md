# IDEA — الأديب الذكي (كلام المالك كما هو)

فكرة المشروع:
" الأديب الذكي" هو عبارة عن أداة ذكاء اصطناعي تفاعلية تهدف إلى تيسير الوصول إلى التراث العربي والكتب، وتستطيع الإجابة عن أي سؤال بدقة استناداً إلى نصوص الكتب، مع ميزة القراءة الصوتية للنصوص بأصوات متعددة وإمكانية مواصلة الاستماع حتى وإن كان الهاتف مغلقاً. يعتمد المشروع على أسلوب مجاني بالكامل وآمن قانونياً وتقنياً باستخدام التخزين السحابي المجاني والبحث المحلي.

--------------------------------------------------
المرحلة الأولى: إعداد التخزين المجاني على GitHub
--------------------------------------------------
1. توجه إلى موقع غيت هاب (github.com) وسجّل دخولك أو أنشئ حساباً مجانياً جديداً.
2. أنشئ مستودعاً جديداً (New Repository) وسمّه مثلاً: `arabic-heritage-library`.
3. اجعل المستودع عاماً (Public) لتتمكن من جلب الروابط منه بسهولة برمجياً.
4. جهّز كتبك التراثية بصيغة ملفات نصية منظمة (مثل صيغة JSON أو TXT).
   - مثال لهيكل ملف الـ JSON:
     {
       "book_title": "اسم الكتاب",
       "author": "اسم المؤلف",
       "sections": [
         {"section": "الباب الأول", "content": "نص الفقرة أو الصفحة..."}
       ]
     }
5. ارفع الملفات إلى مستودع غيت هاب. وللحصول على الرابط المباشر لأي ملف، افتحه على غيت هاب ثم اضغط على زر (Raw) وانسخ رابطه لاستخدامه في الكود.

--------------------------------------------------
المرحلة الثانية: بناء كود البحث المحلي (Python)
--------------------------------------------------
أنشئ ملف بايثون (مثلاً `app.py`) على جهازك، واستخدم هذا الكود الأساسي لجلب الكتاب من غيت هاب والبحث فيه:

```python
import requests
import json

# ضع هنا الرابط المباشر (Raw Link) للملف على غيت هاب
RAW_GITHUB_URL = "https://raw.githubusercontent.com/اسم_حسابك/arabic-heritage-library/main/book_sample.json"

def load_and_search_book(keyword):
    response = requests.get(RAW_GITHUB_URL)
    if response.status_code == 200:
        book_data = response.json()
        results = []
        for section in book_data.get("sections", []):
            if keyword in section["content"]:
                results.append(section)
        return results
    else:
        return "تعذر جلب البيانات من غيت هاب."

# مثال لتجربة البحث

```

--------------------------------------------------
المرحلة الثالثة: تطوير المشروع مستقبلاً
--------------------------------------------------
1. ربط نتائج البحث بنموذج ذكاء اصطناعي محلي (مثل Ollama) لتوليد إجابات دقيقة.
2. دمج مكتبات تحويل النص إلى صوت (TTS) لإضافة ميزة القراءة الصوتية وتشغيلها في الخلفية.
