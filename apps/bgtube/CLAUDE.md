# BGTube — عقل المشروع

## ما هو
تطبيق أندرويد شخصي (APK بدون متجر) يشغّل صوت يوتيوب في الخلفية مع شاشة مغلقة، مع تسجيل دخول جوجل لاستعراض القوائم والإعجابات والاشتراكات والبحث. عربي RTL أولاً ثم إنجليزي، ثيم داكن. مستخدم واحد.

## الملفات
IDEA.md، ANSWERS.md، SPEC.md (المطلوب)، ARCHITECTURE.md (التصميم)، DECISIONS.md (القرارات والمخاطر).

## التقنية
Flutter (أندرويد فقط الآن). بلا Firebase؛ تخزين محلي (drift). التشغيل: just_audio + audio_service + audio_session. الحالة: Riverpod. التنقل: go_router. الدخول: google_sign_in. API: YouTube Data API v3 عبر dio.

## الأوامر (بعد إنشاء المشروع بـ `flutter create`)
- تشغيل: `flutter run` (جهاز أندرويد حقيقي مفضّل للاختبار الخلفي)
- فحص: `flutter analyze`
- اختبار: `flutter test`
- توليد drift: `dart run build_runner build --delete-conflicting-outputs`
- توليد اللغات: `flutter gen-l10n`
- بناء APK: `flutter build apk --release`

## قواعد الكود
1. طبقات: `domain` (نقية) ← `data` تنفّذها ← `features`/`audio` تعتمد على `domain` فقط.
2. الاستخراج غير الرسمي في `lib/data/extractor/` وحده، خلف `AudioSourceResolver`. ممنوع تمرير أي رمز دخول أو كوكي أو معلومة حساب إليه، وممنوع أن يستورده أحد خارج ربط المزوّدات.
3. لا مفاتيح ولا كلمات مرور ولا رموز في الكود أو السجلات أو git. القيم في `.env` (مستثنى من git)، و`.env.example` بأسماء فقط. لا client secret أبداً.
4. الرموز لا تُخزَّن إلا عبر flutter_secure_storage وبأقل ما يلزم؛ الخروج يمسحها.
5. كل نص واجهة من ARB (ar أولاً)؛ لا نص ثابت في الشاشات؛ استخدم `EdgeInsetsDirectional` و`start/end` لا left/right.
6. كل طلب API يمر بالكاش وعدّاد الحصة؛ فضّل الطلبات ذات الوحدة الواحدة على `search.list`؛ لا تحديث تلقائي.
7. كل فشل يتحول إلى `AppFailure` برسالة عربية واضحة وزر إعادة المحاولة؛ لا انهيار.
8. أقل بيانات: لا تحليلات ولا أعطال خارجية ولا إعلانات.
9. اكتب اختباراً مع كل منطق جديد (انظر قسم الاختبارات في ARCHITECTURE.md). لا تقل إن شيئاً يعمل قبل تشغيله واختباره فعلاً.
10. أي قرار مهم جديد يُسجَّل في DECISIONS.md.

## تنبيهات المالك (من القواعد العامة)
- لا دفع ولا نشر ولا حذف بيانات ولا رسائل لأشخاص دون موافقة صريحة.
- إذا احتجت حساباً أو مفتاحاً (مشروع Google Cloud وOAuth client) أو قراراً (انتهاء رمز الاختبار 7 أيام: أ أم ب) فتوقف واسأل سؤالاً واحداً. نبني بوضع تجريبي (لصق رابط وتشغيل) حتى تتوفر المفاتيح.
- الاستخراج مخالف لشروط يوتيوب (D10): للاستخدام الشخصي فقط، لا متجر.
