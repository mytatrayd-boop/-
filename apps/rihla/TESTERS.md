# المختبرون — تثبيت نسخة «رحلة» التجريبية (أندرويد)
1. افتح صفحة GitHub للمستودع > Actions > آخر تشغيل ناجح لـ «Rihla — Android test APK».
2. في أسفل الصفحة (Artifacts) نزّل الملف rihla-apk (يلزم تسجيل الدخول لحساب لديه صلاحية).
3. فكّ ضغط الملف المضغوط (zip) على الجوال لتحصل على app-release.apk.
4. افتح app-release.apk، وإذا طلب الجوال فاسمح لمتصفحك/مدير الملفات بـ«التثبيت من مصادر غير معروفة».
5. اضغط «تثبيت» (وإذا ظهر تحذير Play Protect فاختر «التثبيت على أي حال»)، ثم افتح التطبيق.
6. سجّل ملاحظاتك (حرج / مهم / تحسين) مع خطوات إعادة المشكلة وأرسلها ليُضاف إلى FEEDBACK.md.
