## التطبيق
يعرض لليوم: الدَّرّ والموسم الكبير وموسم الجو والنجم والجو المعتاد حسب التراث لمنطقة المستخدم (4 جداول)، في دائرة تفاعلية، مع التاريخين الهجري (أم القرى) والميلادي، وتنبيهات محلية للمواسم المهمة. يعمل كاملاً بلا إنترنت ببيانات مضمّنة، بلا خادم ولا حساب، ويحدّث بياناته اختيارياً من ملفات موقّعة عند توفر الإنترنت (ARCHITECTURE §16). العربية فقط في الإطلاق.

المراجع: `IDEA.md` (الفكرة وإجابات المالك)، `SPEC.md` (الميزات ومعايير القبول)، `ARCHITECTURE.md` (التصميم التقني)، `DECISIONS.md` (القرارات وأسبابها)، `STATUS.md` (حالة العمل).

## التقنية
- Flutter stable (3.47.6) / Dart 3.13.5، المنصتان android وios فقط.
- Riverpod 3 (بلا توليد كود)، go_router، gen-l10n (ARB).
- **بلا Firebase ولا خادم** (DECISIONS D1). البيانات أصول JSON في `assets/tables/`.
- المكتبات وإصداراتها: ARCHITECTURE §14. لا تُضف مكتبة إلا مستقرة ومشهورة، وسجّل السبب في DECISIONS.md.

## الأوامر (من داخل `apps/durur/`)
Flutter في هذه البيئة: `/home/user/flutter/bin/flutter` (أضفه للـ PATH أو استخدم المسار كاملاً).
```
flutter pub get
flutter gen-l10n                     # بعد تعديل lib/l10n/app_ar.arb (يحدث تلقائياً مع pub get)
flutter analyze                      # يجب: No issues found
flutter test                         # يجب: All tests passed
flutter run --dart-define-from-file=config/app_config.json
dart run tool/validate_tables.dart --release   # قبل أي بناء إصدار (يُضاف مع الميزة 1)
```
`config/app_config.json` يُنسخ من `config/app_config.example.json` ولا يُرفع إلى git.

## قواعد الكود
- **العربية أولاً ومن اليمين لليسار.** كل نص يراه المستخدم في `lib/l10n/app_ar.arb`، لا نصوص عربية أو إنجليزية مكتوبة داخل الواجهة. نصوص البيانات في JSON بصيغة `{"ar": "..."}`.
- استخدم `EdgeInsetsDirectional` و`AlignmentDirectional` و`start/end` لا `left/right`.
- **لا مفاتيح ولا أسرار ولا عناوين بريد في الكود.** الإعدادات عبر `--dart-define-from-file`. ملفات `.env` والمفاتيح مستثناة في `.gitignore`.
- **الخصوصية:** لا تحليلات، لا تقارير أعطال، لا إعلانات. الموقع تقريبي ومرة واحدة، ولا تُحفظ الإحداثيات (يُحفظ معرّف المدينة فقط). إذن INTERNET لأندرويد مسموح فقط لتحديث البيانات الموقّعة (D21، بموافقة المالك)؛ لا أي طلب شبكة آخر، ولا معرّفات أو معاملات في طلب التحديث.
- الطبقات `domain/` و`engine/` و`astronomy/` ومخطِّط التنبيهات: **Dart صافٍ** بلا استيراد Flutter، ومعها اختبارات وحدة.
- التواريخ: «اليوم» يبدأ منتصف الليل بتوقيت الجهاز؛ حساب الفروق بـ `DateTime.utc(y, m, d)`.
- كل سجل بيانات له `source` و`approval`. لا تكتب بيانات تراثية من الذاكرة؛ من مصدر منشور ومعلّمة `draft`.
- لا تنسخ أي نص أو رسم من ملصق s3eed.elm6awa3.
- لا تسمِّ أي مجلد `data` (مستثنى في `.gitignore` الجذري).
- لا تقل إن شيئاً يعمل قبل `flutter analyze` و`flutter test` ناجحين. ما لا يمكن اختباره هنا (بناء أندرويد/آيفون، التنبيهات الفعلية) يُذكر صراحةً أنه لم يُختبر.
- لا `build/` ولا ملفات بناء في git.
