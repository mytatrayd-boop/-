## 2026-10-31 — المسار المجاني بلا بطاقة (قرار المالك) — يحلّ محل قرارات Vertex/Functions/Places
- **يُلغى:** Cloud Functions، Vertex AI، Places API، Blaze، `cloud_functions`، دليل «بلا مفتاح» عبر Secret Manager. قرار «أداة الجدوى عبر Vertex REST» أعلاه يُستبدل: الأداة تستدعي Gemini API (AI Studio) بـ`GEMINI_API_KEY` من البيئة. تعديل الأداة مهمة تنفيذ منفصلة.
- **الوسيط:** Cloudflare Worker لأنه مجاني بلا بطاقة، يدعم الأسرار، ويتحقق من JWT بـWebCrypto. المفتاح سر Worker فقط.
- **التحقق:** Firebase ID token + App Check token بمفاتيح JWKS العامة داخل Worker، بلا Admin SDK ولا حساب خدمة.
- **الحصة والمعدل والسقف اليومي:** Durable Objects (SQLite) بدل Firestore. السبب: ذرّية، وFirestore من Worker يحتاج حساب خدمة وسراً إضافياً. بديل إن تعذر DO مجاناً: Firestore REST بحساب خدمة. Firestore يبقى للملاحظات فقط (إنشاء فقط).
- **حالة الضيف:** تُستنتج من claim الموفّر في التوكن لا من العميل. ثغرة إعادة التثبيت مقبولة في التجربة.
- **السقف اليومي الكلي:** `DAILY_CAP` أقل من حد Gemini المجاني؛ عند بلوغه أو عند 429 تظهر «الخدمة مشغولة» ولا تُحتسب. الحدود تتغير فتُتحقق وقت البناء.
- **المقهى:** `geolocator` عند الضغط فقط، جدول `cafes` محلي (الاسم إلزامي، الإحداثيات اختيارية)، رابط `maps/search/?api=1&query=lat,lng` يُبنى وقت الاستخدام. يُحذف `placeId/placeUrl` من التصميم.
- **تخزين صور المساهمة:** Workers KV. Firebase Storage وR2 يتطلبان بطاقة. السعة ~1GB و~1000 كتابة/يوم تكفي 20–30 مختبراً. بديل: D1 ثم جمع يدوي. الصور بمعرّف عشوائي بلا uid؛ السحب بحذف المعرّف المحفوظ محلياً.
- **الجوال كطريقة دخول:** رسائل SMS قد تتطلب Blaze أو حداً ضيقاً على Spark. يُتحقق قبل البناء؛ إن لم يتوفر مجاناً نكتفي بـGoogle (وApple عند آيفون).
- **الخصوصية:** الطبقة المجانية قد تسمح لقوقل بتحسين منتجاتها بالمحتوى، وقد تُقيّد الاتحاد الأوروبي/بريطانيا/سويسرا. إفصاح قبل أول فحص، والتجربة للسعودية/الخليج.
- **الترتيب:** المستقل عن الوسيط (المفضلة، المقهى، المشاركة) ثم الجدوى والوسيط. هذا يعدّل قاعدة «لا تبنِ قبل الجدوى» لتشمل الميزات المعتمدة على الوسيط فقط (ARCHITECTURE §11).
- **النموذج الخاص (TFLite):** تدريب خارج التطبيق على بيانات المساهمة + تقييم خبير، ودمج عبر `tflite_flutter` خلف `AnalysisService` نفسه. التفاصيل ARCHITECTURE §12.
