# أدوات استيراد نماذج الأسئلة (للمتابعة في جلسة جديدة)

تُشغَّل من مجلد يحوي هذه الملفات + `skills.json` (من `dump-skills.mjs`) ومجلدات: `tj/` (محتوى «تجميع.zip» بأسماء عربية)، `formout/`.
المتطلبات: Python 3 مع PyMuPDF (fitz) وPillow (دعم WebP).

## الإجراء لكل نموذج بلا مفتاح (مفاتيح الموقع)
1. `python3 extract_form.py "<ملف.pdf>" <وسم> ` ← يقصّ كل سؤال (جدول بحدود) وكل نص إلى `formout/<وسم>/*.webp` + `formout/<وسم>.json`.
   - القاعدة: سؤال = كتلة بين خطوط الجدول الكاملة فيها رقم أو خيار «أ»؛ نص = كتلة طويلة بلا رقم ولا «أ».
   - عيوب معروفة: صف الخيارات المنقسم بين صفحتين (يُدمج بـ `fix`)، وكتلة نص فيها أرقام قوائم تُحسب سؤالاً (تُحذف يدوياً وتصير نصاً)، وصفحات علوم بتنسيق مختلف تحتاج فحصاً.
2. `python3 sheets2.py <وسم>` ← يصنع `bank/sh_<وسم>_N.png` (9 أسئلة لكل صورة) للقراءة والحل.
3. يُحَلّ كل سؤال ويُسجَّل: الإجابة (أ ب ج د) والمؤشر والمستوى (know/apply/reason) من `skills.json`.
4. `buildsolved.py`: `add(...)` لنموذج بمادة واحدة، و`add_form(...)` لنموذج متعدد المواد، يكتب `public/bank-official/solved.json` وينسخ الصور إلى `public/bank-official/solved/`.
5. `npm test` ثم commit.

## المنجز
- الثالث الابتدائي نماذج 01–05 (قراءة)، السادس نماذج 01–05 (رياضيات 25 + قراءة 25 + علوم 30 لكل نموذج).
## المتبقي (من «تجميع.zip»، بلا مفاتيح)
- السادس: «اختبار رياضيات الصف السادس 1 و2»، «أسئلة الصف ٦ب رياضيات وعلوم وقراءة»، نصوص القراءة («الاتصالات وسحابة الرماد البركاني»، «خصب المخيلة»، «قنديل البحر»).
- الثالث المتوسط: «أسئلة رياضيات وعلوم وقراءة ٣م»، «أنموذج تجريبي - الاختبارات الوطنية 3م».
## قرارات المالك
- المفتاح من حلّ الموقع ويُعلَن أنه غير رسمي (العنوان «(مفتاح الموقع)» وتنبيه عند الإضافة)؛ لا نشر ولا دمج بدون قوله «انشر»/«ادمج».
- ما ليس له مفتاح رسمي ولم نحلّه يبقى في PENDING-MATERIALS.md.

## أدوات التقطيع (بعد extract_form.py القديم الذي يفشل في بعض الملفات)
- `blocks_split.py <pdf> <وسم> <صفحات القراءة>`: كتل متصلة؛ يفصل النص (صندوق بخط عمودي طويل) عن الأسئلة. **يكتب الملف كاملاً فشغّله أولاً.**
- `rows_split.py <pdf> <وسم> <صفحات الرياضيات>`: جدول بعمود رقم وعمود خيار (أرقام الرياضيات بخط مرمّز M..V = 0..9).
- `sci_split.py <pdf> <وسم> <صفحات العلوم>`: يقطع بحسب رمز رقم السؤال على اليمين.
- `mksheet.py <وسم> <من> <إلى> <صورة>`: ورقة معاينة للقراءة والحل.
- الترتيب في ملف الوسم: قراءة ← رياضيات ← علوم؛ ثم `add_form`.
- عيوب بقيت: صور بعض أسئلة العلوم الأخيرة في الصفحة تحوي تذييل «من 14»؛ وبعض صور الأسئلة تحوي ترويسة الصفحة.
- `bands.py`: تقطيع الصفحات بالفجوات البيضاء (للملفات بجداول بلا خطوط متجهية)؛ `manual_crop.py` لقصّ يدوي.
