# أدوات استيراد نماذج الأسئلة (للمتابعة في جلسة جديدة)

تُشغَّل من مجلد يحوي هذه الملفات + `skills.json` (من `dump-skills.mjs`) ومجلدات: `tj/` (محتوى «تجميع.zip» بأسماء عربية)، `formout/`.
المتطلبات: Python 3 مع PyMuPDF (fitz) وPillow (دعم WebP).

## الإجراء لكل نموذج بلا مفتاح (مفاتيح الموقع)
1. `python3 extract_form.py "<ملف.pdf>" <وسم> ` ← يقصّ كل سؤال (جدول بحدود) وكل نص إلى `formout/<وسم>/*.webp` + `formout/<وسم>.json`.
   - القاعدة: سؤال = كتلة بين خطوط الجدول الكاملة فيها رقم أو خيار «أ»؛ نص = كتلة طويلة بلا رقم ولا «أ».
   - عيوب معروفة: صف الخيارات المنقسم بين صفحتين (يُدمج بـ `fix`)، وكتلة نص فيها أرقام قوائم تُحسب سؤالاً (تُحذف يدوياً وتصير نصاً)، وصفحات علوم بتنسيق مختلف تحتاج فحصاً.
2. `python3 sheets2.py <وسم>` ← يصنع `bank/sh_<وسم>_N.png` (9 أسئلة لكل صورة) للقراءة والحل.
3. يُحَلّ كل سؤال ويُسجَّل: الإجابة (أ ب ج د) والمؤشر والمستوى (know/apply/reason) من `skills.json`.
4. `buildsolved.py`: `add(...)` لنموذج بمادة واحدة، و`add_form(...)` لنموذج متعدد المواد، يكتب `public/bank-official/solved.json` وينسخ الصور إلى `public/bank-official/solved/`.
5. `npm test` ثم commit.
