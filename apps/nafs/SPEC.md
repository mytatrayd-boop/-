# المتطلبات

## المعلم
- إنشاء حساب: الاسم الثلاثي، السجل المدني (10 أرقام)، المدرسة، الصف والفصل، البريد، كلمة المرور.
- دخول بالبريد وكلمة المرور، ويبقى داخلاً بعد إغلاق المتصفح. «نسيت كلمة المرور» يرسل رابطاً للبريد.
- تغيير الفصل الحالي من اللوحة (الفصول التسعة نفسها في الأصل).
- إضافة طالب فردياً (الاسم + السجل المدني) أو استيراد من أكسل (XLSX/XLS، عمودان بأي ترتيب).
- **الملف المرفوع نفسه يُحفظ** في الحساب (حتى 700KB) ويمكن تنزيله أو حذفه لاحقاً.
- حذف طالب أو كل طلاب الفصل — مع رسالة تأكيد.
- التقارير: العدد، متوسط الإتقان، المنجزون، جدول تفصيلي، تصدير CSV.
- الطالب مسجل عند معلم واحد؛ محاولة إضافته عند معلم آخر تُرفض برسالة.

## الطالب
- يدخل برقم السجل المدني فقط (كما في الأصل)، يقرأ النص ويجيب سؤالين، وتُحفظ النتيجة عند معلمه.

## خارج النطاق الآن
- أكثر من نص/اختبار، أو اختبارات يحددها المعلم.
- لوحة للمشرف تجمع كل المعلمين.
- الإنجليزية (الواجهة عربية فقط حالياً).
