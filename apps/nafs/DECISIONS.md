# القرارات

1. **موقع ويب وليس Flutter** — المالك طلب «موقع برابط». Firebase باقٍ كخلفية حسب القاعدة العامة.
2. **الملفات المرفوعة تُحفظ داخل Firestore (base64) لا في Cloud Storage** — Storage يتطلب خطة Blaze المدفوعة للمشاريع الجديدة، وملفات قوائم الطلاب صغيرة. الحد 700KB للملف.
3. **دخول الطالب برقم السجل المدني فقط** كما في الأصل. النتيجة: من يعرف رقم طالب يستطيع رؤية اسمه ونتيجته وإرسال اختبار باسمه. يمكن لاحقاً إضافة رمز سري لكل طالب إن أراد المالك.
4. **النشر عبر REST وليس firebase-tools** — مفتاح Admin SDK لا يملك صلاحيات Service Usage التي يطلبها firebase-tools (نفس تجربة مشروع أسرتي).
5. **SheetJS 0.18.5 من npm** — آخر نسخة على npm؛ لها ثغرة معروفة عند قراءة ملفات خبيثة، لكن الملف يُقرأ في متصفح المعلم الذي رفعه فقط، فالأثر محصور به.
6. **Tailwind يُبنى وقت البناء** بدل CDN (CDN غير مخصص للإنتاج).
