# ابدأ من هنا

## قبل فتح Claude Code
1. ثبّت **Flutter SDK** و **Android Studio**. لبناء نسخة iPhone تحتاج جهاز **Mac** مع Xcode.
2. أنشئ مشروعاً على **Firebase** (console.firebase.google.com). الـ Cloud Functions تحتاج تفعيل خطة الدفع حسب الاستخدام (Blaze)، وتكلفتها في البداية شبه معدومة لعدد قليل من الأسر.
3. أنشئ حساباً في خدمة إرسال بريد (مثل Resend) لإرسال أكواد التحقق.
4. للنشر لاحقاً: حساب **Apple Developer** وحساب **Google Play Console**.

## أول رسالة ترسلها لـ Claude Code
افتح هذا المجلد في Claude Code، ثم الصق:

```
هذا مشروع تطبيق "أسرتي". اقرأ CLAUDE.md و docs/SPEC.md كاملين، وافتح design/prototype.html وافهم كل شاشاته ومنطقه.
بعدها اعرض عليّ خطة المرحلة 1 من SPEC.md §10 (الملفات والحزم والخطوات)، واسألني عن أي شيء ناقص قبل ما تبدأ.
لا تبدأ الكتابة قبل ما أوافق على الخطة.
```

## نصائح
- اعمل مرحلة واحدة في كل مرة، وجرّب التطبيق على جوالك قبل الانتقال للتالية.
- إذا غيّرت أي قرار (مثل الصلاحيات أو المكافآت)، اطلب من Claude Code تحديث `docs/SPEC.md` أولاً، ثم الكود.
- لا تضع مفاتيح API أو كلمات مرور داخل الكود أو المحادثة. استخدم Firebase Secrets.
