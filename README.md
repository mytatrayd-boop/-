# راصد (Rased) — تطبيق جوال

يرشّح **أقوى سهمين** أسبوعيًا من **السوق الأمريكي كامل** (أو من قائمتك): سيولة غير طبيعية (بوابة إلزامية) × زخم RSI(14)، مع دخول/هدف/وقف وفلتر يقين الشرعي. التطبيق PWA يُثبَّت كأيقونة على الجوال (iPhone: مشاركة ← إضافة للشاشة الرئيسية، Android: تثبيت التطبيق).

> ليس توصية مالية. المنطق **لم يُختبر تاريخيًا**.

## التشغيل

```bash
cp .env.example .env      # ضع MASSIVE_API_KEY و ALPHA_VANTAGE_KEY
npm run check:massive     # مرة واحدة: يتحقق من شكل ردود Massive الحقيقية بمفتاحك
npm start                 # http://localhost:3000
npm test
```

| المفتاح | من أين | يستخدم لـ |
|---|---|---|
| `MASSIVE_API_KEY` | massive.com (Polygon سابقًا) — الخطة المجانية | أسعار السوق الأمريكي كامل |
| `ALPHA_VANTAGE_KEY` | alphavantage.co — مجاني | الأخبار وتقويم الأرباح (وأسعار «قائمتي» لو ما فيه Massive) |

بدون أي مفتاح يشتغل الخادم في **وضع تجريبي** ببيانات مصطنعة، وتُوسم في الواجهة بوضوح ("وضع تجريبي" / "بيانات تجريبية").

لا توجد أي مكتبات خارجية — Node 18+ فقط. أي استضافة Node تكفي (Railway / Render / Fly): أمر التشغيل `npm start`، والمفتاحين كمتغيرات بيئة، و**قرص دائم** مربوط على `DATA_DIR` (وإلا تُعاد التعبئة الأولى بعد كل إعادة تشغيل).

## السوق الأمريكي كامل (Massive)

- طلب «Grouped Daily» واحد يرجع شمعة يوم لكل الأسهم الأمريكية. الخادم يخزّن كل يوم في `data/days/YYYY-MM-DD.json` ويحتفظ بآخر 70 يوم تداول.
- **أول تشغيل**: تعبئة ~66 يوم عمل بحد الخطة المجانية (5 طلبات/دقيقة) ≈ **15 دقيقة**. الشارة فوق تعرض «يتجهز X/60 يوم»، ومسح السوق كامل يشتغل بعد 30 يوم على الأقل.
- **بعدها**: الخادم يفحص كل ساعة ويضيف يوم التداول الجديد (طلب واحد). المسح نفسه ما يستهلك أي طلب أسعار — يحسب من المخزن.
- **الكون**: أسهم عادية فقط (`type=CS`، تتحدث أسبوعيًا — بدون صناديق ولا وارنتات)، تداولت في آخر يوم، سعرها ≥ $5، ومتوسط قيمة تداولها اليومية ≥ $20M (قابلة للتعديل من الإعدادات). بدون هذا الفلتر تسيطر الأسهم الخاملة على «السيولة غير الطبيعية».
- البيانات **نهاية اليوم** (الخطة المجانية) — تناسب أفق أسبوع: امسح بعد الإغلاق.
- الأخبار والأرباح تبقى من Alpha Vantage، فقط لأقوى الأسهم اللي اجتازت السيولة (حد 5)، فالحصة المجانية تكفي.
- **يقين**: ما فيه أحكام إلا اللي تدخلها، فأغلب ترشيحات السوق كامل تطلع «غير معروف» — شاشة يقين تعرض الترشيحات أولاً عشان تحكم عليها بسرعة.

## تطبيق الأندرويد (APK) — بدون خادم

التطبيق نفسه داخل ملف APK، ويجلب الأسعار **مباشرة من الجوال** بمفتاحك (بدون Railway ولا خادم):

1. حمّل `rased.apk` من آخر Release في المستودع (`releases/latest`) وثبّته (اسمح بالتثبيت من مصادر غير معروفة).
2. الإعدادات ← **المفاتيح** ← الصق مفتاح Massive (و Alpha Vantage اختياري) ← حفظ.
3. خلّ التطبيق مفتوح أول مرة (~15 دقيقة، الشاشة تبقى شغالة) لين الإشارة فوق تصير 🟢.

- البناء تلقائي في GitHub Actions (`.github/workflows/rased-android.yml`): كل دفع للفرع الأساسي ينشر Release جديد.
- الطلبات تمر من جسر Java (`RasedNative`) لأن WebView يمنع طلبات الصفحة المحلية لمواقع ثانية؛ الجسر يقبل فقط مواقع Massive و Alpha Vantage.
- أيام السوق تُخزّن في IndexedDB على الجوال، والمفاتيح في تخزين التطبيق فقط.
- ⚠️ `android/rased-sideload.p12` مفتاح توقيع مكشوف في المستودع عمدًا — للتثبيت المباشر فقط، عشان التحديثات تنثبت فوق النسخة القديمة. لا تستخدمه لنشر في متجر.
- البناء محليًا: `node scripts/build-android.mjs && gradle -p android assembleRelease` (يحتاج Android SDK).

## تجربة سريعة بدون خادم

```bash
npm run build:standalone   # → dist/rased-standalone.html
```

ملف واحد فيه التطبيق كاملًا بوضع تجريبي (نفس الواجهة ونفس منطق المسح في `server/scan.js`، مع بيانات مصطنعة). مناسب للمعاينة على الجوال أو النشر كـ Claude Artifact.

## البنية

| الملف | الدور |
|---|---|
| `server/engine.js` | منطق النموذج الأولي منقول كما هو: `barsFromAlphaVantage` (JSON + CSV)، `scoreTicker`، `buildTrade`، فلتر يقين |
| `server/alphavantage.js` | جلب الأسعار والأخبار وتقويم الأرباح بالمفتاح (يبقى في الخادم فقط)، طابور بفاصل 1.1 ثانية (حد الثانية الواحدة)، تخزين مؤقت (4 ساعات، والأرباح 24 ساعة)، كشف تجاوز الحصة |
| `server/massive.js` | أسعار السوق كامل من Massive: تحليل الردود، مخزن الأيام على القرص، المزامنة (12.5 ثانية بين الطلبات)، فلتر الكون |
| `server/scan.js` | تنسيق المسح (أسعار → سيولة → أخبار → أرباح → ترتيب)، بدون اعتماد على Node — يشغّله الخادم والنسخة المستقلة |
| `server/index.js` | خادم HTTP: `POST /api/scan`، `GET /api/health`، ويخدم `public/` |
| `public/` | واجهة الجوال: الترشيحات، كل الأسهم، يقين، الإعدادات |

## شاشات التطبيق

- **الترشيحات**: بطاقة لكل سهم (أعلى 2) — اسم الشركة الكامل والبورصة (NASDAQ / NYSE) مع رابط «السعر الحقيقي» في Yahoo Finance، الاتجاه، **مصدر الترشيح** (سيولة / فني / خبر مع أهم العناوين)، تنبيه أرباح داخل الأسبوع، الدخول والهدف والوقف مع النسبة، شارت شموع 60 يوم، حكم يقين ورابط التحقق.
- **كل الأسهم**: نتيجة كل سهم (مؤهّل / سيولة ضعيفة / خبر معاكس / فشل / مستبعد بيقين) مع أثر الخبر.
- **يقين**: حكم لكل سهم بضغطة (ضغطة ثانية = غير معروف) + مفاتيح الاستبعاد.
- **شارة الحالة** (فوق): 🔴 تجريبي أو المزامنة متوقفة، 🟡 تتجهز أو بيانات قديمة، 🟢 أسعار حقيقية والمزامنة شغالة. اضغطها تشوف السبب ووش تسوي.
- **الإعدادات**: نطاق المسح (السوق كامل / قائمتي) وفلتر السعر والسيولة، قائمتي (حد 25) مع حساب استهلاك الحصة، بوابة السيولة، الأخبار، معاملات الصفقة. كلها محفوظة على الجهاز.

## التسجيل

```
1. بوابة السيولة (إلزامية): حجم اليوم ÷ متوسط N يوم (باستثناء اليوم) ≥ المضاعف، وإلا النتيجة صفر
2. RSI(14): الاتجاه (≥50 صاعد) وقوة الزخم |RSI−50|/50
3. النتيجة الأساسية = نسبة السيولة × قوة الزخم
4. الخبر (NEWS_SENTIMENT) — بوابة لينة + تعزيز، فقط لمن اجتاز السيولة، الأقوى أولاً حتى newsMax طلب:
   - المشاعر = متوسط مشاعر المقالات للسهم مرجّح بالصلة (صلة ≥ 0.3، آخر newsDays يوم)
   - المتوافق = المشاعر × الاتجاه
   - متوافق ≤ −حد الاستبعاد (0.35) → مستبعد
   - وإلا النتيجة × (1 + clamp(متوافق/الحد, −1, 1) × أقصى تعزيز)   → من ×0.5 إلى ×1.5 افتراضيًا
   - لا يوجد خبر / لم يُفحص / فشل الجلب → ×1 (محايد)، ويُعرض السبب صراحة
5. الأرباح (EARNINGS_CALENDAR، طلب واحد للسوق): تنبيه مخاطرة لو الإعلان داخل 7 أيام — لا يغيّر النتيجة
6. الترتيب تنازليًا، أقوى سهمين
```

أسوأ استهلاك لمسح واحد: عدد الأسهم + min(newsMax، عدد الأسهم) + 1. القائمة الافتراضية: 12 + 5 + 1 = 18 من 25.

### ما لم يُتحقق منه بعد ⚠️

- **شكل ردود Massive** (`results[].T/o/h/l/c/v` و`/v3/reference/tickers`) مبني على التوثيق — الشبكة في بيئة التطوير تحجب النطاق. شغّل `npm run check:massive` بمفتاحك قبل الاعتماد عليه.
- **شكل رد `NEWS_SENTIMENT` الكامل** (`feed[].ticker_sentiment[]`) مبني على التوثيق — الحصة كانت منتهية وقت الكتابة. المحلل دفاعي (أي مقال ناقص يُتجاهل، وأي رد بدون `feed` = خطأ واضح)، لكن لازم مسح حي واحد للتأكد.
- **ترويسة `EARNINGS_CALENDAR` مؤكدة** من رد حقيقي. ولوحظ فعليًا أن رسالة تجاوز الحصة ترجع أحيانًا مقطّعة كصف CSV (`I,n,f,o,r,m,a`) — المحلل يرفضها.

## الخطوات التالية

1. مسح حي واحد للتحقق من شكل رد الأخبار.
2. اختبار تاريخي صارم (الدخول بسعر الشمعة التالية، عمولة وتكلفة) قبل الثقة بأي نتيجة.
3. السوق السعودي — يحتاج مزوّد بيانات.
